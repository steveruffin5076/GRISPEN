# GRISPEN — AI ART PROMPTS
## For Midjourney / DALL·E / Stable Diffusion / Flux

Use these prompts to generate sprites, tilesets, UI elements, and promotional art for GRISPEN. Every prompt is written to match the signature **ballpoint-pen-on-paper, monochrome + selective red accent** art style defined in the GDD.

---

## 🔑 SHARED STYLE KEYWORDS (append to every prompt unless noted)

```
top-down view, bird's eye perspective, zenithal overhead angle, hand-drawn ballpoint pen sketch, cross-hatching, stippling, pen-and-ink comic book art, monochrome grayscale on off-white paper background, subtle paper texture, visible ink line weight variation, sketchy imperfect lines, black and white with only selective crimson red accents for blood, clean silhouette, centered, transparent background (when sprite), 2D game asset, stylized --no 3d render, realistic, photorealistic, blurry, watermark, text
```

A shorter version for use inside larger prompts:

```
top-down view, ballpoint pen sketch, cross-hatching, monochrome on off-white paper, selective red accents, transparent background, 2D game sprite
```

## ⚙️ RECOMMENDED GENERATION SETTINGS

- **Midjourney:** `--ar 1:1` for sprites, `--ar 16:9` for key art. Use `--style raw` to reduce over-painting. Append `--no background` for sprites then post-process to transparency.
- **DALL·E 3 / ChatGPT:** Use the full prompt above; it tends to produce a cleaner comic style natively.
- **Stable Diffusion / Flux:** Use Euler a sampler, CFG ~7, steps ~28. Recommended LoRAs: *Ink Art*, *Comic Book Style*, *2D Game Assets*.
- **Post-processing:**
  1. Crop to tight square (sprites) or the intended UI size.
  2. Remove background (use a tool like remove.bg or Photoshop "Select Subject").
  3. Downscale to final in-game size (Phaser scales sprites up/down as needed; base at ~128×128 for characters, ~256×256 for buildings).
  4. Run a slight sharpen filter to crisp up pen lines.
  5. Save as PNG-24 with alpha transparency.
